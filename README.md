# Bill K.P. — ระบบออกใบเสร็จรับเงิน / ใบกำกับภาษี

เวอร์ชันอัปเกรดของ `WebBillKP` — ย้ายจาก Vite SPA ที่เก็บข้อมูลใน `localStorage`
มาเป็น Next.js + MongoDB Atlas พร้อมระบบล็อกอิน deploy ขึ้น Vercel ใช้งานจริงได้

| | เดิม | ใหม่ |
|---|---|---|
| โครงสร้าง | Vite SPA | Next.js 16 (App Router) |
| ที่เก็บข้อมูล | `localStorage` ในเครื่องเดียว | MongoDB Atlas |
| การเข้าถึง | ใครเปิดไฟล์ก็ใช้ได้ | Google login + allowlist อีเมล |
| ออก PDF | html2canvas → รูป JPEG ฝังใน PDF | ระบบพิมพ์ของเบราว์เซอร์ → **ตัวหนังสือ vector** |
| การคำนวณเงิน | string แยกบาท/สตางค์ | จำนวนเต็มสตางค์ |
| เทส | ไม่มี | 65 เทส (`npm test`) |

## ตั้งค่า environment (4 อย่าง)

### 1. `AUTH_SECRET`

```bash
npx auth secret
```

### 2. Google OAuth → `AUTH_GOOGLE_ID` / `AUTH_GOOGLE_SECRET`

1. เปิด [Google Cloud Console](https://console.cloud.google.com/apis/credentials) → สร้าง project
2. **OAuth consent screen** → เลือก **External** → กรอกชื่อแอปกับอีเมลติดต่อ
   (ไม่ต้องส่ง verify เพราะจำกัดผู้ใช้ด้วย allowlist อยู่แล้ว)
3. **Credentials → Create Credentials → OAuth client ID → Web application**
4. ใส่ **Authorized redirect URIs** ทั้งสองอัน:
   ```
   http://localhost:3000/api/auth/callback/google
   https://<ชื่อโปรเจค>.vercel.app/api/auth/callback/google
   ```
5. คัดลอก Client ID / Client secret มาใส่ `.env.local`

### 3. `ALLOWED_EMAILS`

อีเมลที่เข้าใช้งานได้ คั่นด้วยจุลภาค เช่น `somchai@gmail.com,accounting@gmail.com`

> ถ้าไม่ตั้งค่านี้ **จะไม่มีใครเข้าได้เลย** — ตั้งใจให้เป็นแบบนี้ ปลอดภัยกว่าการเผลอ
> เปิดให้ทุกคนที่มีบัญชี Google เข้าถึงใบกำกับภาษีของบริษัท

### 4. `MONGODB_URI` — MongoDB Atlas (ฟรี)

1. สมัคร [MongoDB Atlas](https://www.mongodb.com/cloud/atlas/register) → **Create → M0 (Free)**
   เลือก region **Singapore (ap-southeast-1)** ให้ใกล้ไทยที่สุด
2. **Database Access** → Add New Database User (จด username/password ไว้)
3. **Network Access** → Add IP Address → **Allow access from anywhere (`0.0.0.0/0`)**
   — จำเป็น เพราะ Vercel ไม่มี IP ตายตัว ความปลอดภัยอยู่ที่รหัสผ่านของ database user
4. **Connect → Drivers** → คัดลอก connection string มาใส่ แล้วแทน `<password>` ด้วยรหัสจริง

M0 ให้พื้นที่ 512 MB ≈ บิลราว 340,000 ใบ

## Deploy ขึ้น Vercel

```bash
npm i -g vercel
vercel            # ครั้งแรก: ตอบคำถามผูกโปรเจค
vercel --prod
```

หรือ push ขึ้น GitHub แล้วกด **Import Project** ใน Vercel

**หลัง deploy ต้องทำ 2 อย่าง:**

1. ใส่ environment variables ทั้ง 5 ตัวใน **Project → Settings → Environment Variables**
   (`AUTH_SECRET`, `AUTH_GOOGLE_ID`, `AUTH_GOOGLE_SECRET`, `ALLOWED_EMAILS`, `MONGODB_URI`)
2. เพิ่ม redirect URI ของโดเมนจริงใน Google Cloud Console (ข้อ 2 ด้านบน)

> ⚠️ **Vercel Hobby (ฟรี) อนุญาตเฉพาะงานส่วนตัวที่ไม่ใช่เชิงพาณิชย์** ตาม Fair Use Policy
> ระบบออกบิลของบริษัทถือเป็น commercial use ทางเทคนิค ถ้าอยากอยู่ในกติกาเป๊ะ ๆ
> มีสองทาง: อัป Pro ($20/เดือน) หรือย้ายไป Cloudflare Pages / Netlify ที่ฟรีแบบใช้เชิงพาณิชย์ได้

## เลขที่เอกสาร

รูปแบบ **ปี พ.ศ. / เดือน / เลขรัน** เช่น `2569/08/001` `2569/08/002` …
ขึ้นเดือนใหม่เลขรันเริ่มที่ `001` ใหม่เสมอ

- ระบบเสนอเลขถัดไปให้ตอนเปิดบิลใหม่ โดยดูจากเลขสูงสุด **ของเดือนนั้น**
  (นับรวมบิลในถังขยะด้วย — เลขที่ออกไปแล้วต้องไม่ถูกใช้ซ้ำ)
- เป็นแค่ข้อเสนอ พิมพ์ทับเองได้เสมอ
- บิลเก่าที่นำเข้ามาซึ่งใช้เลขคนละแบบไม่กระทบ — ระบบจะเริ่มนับ `001` ของเดือนนั้นให้
- **เลขซ้ำบันทึกไม่ได้** มี unique index ที่ฐานข้อมูลกันไว้ (ยกเว้นบิลที่ยังไม่กรอกเลข)
  เพราะการเสนอเลขไม่ใช่การจอง เปิดสองแท็บพร้อมกันก็ได้เลขเดียวกันได้

## วันที่บนบิล

ช่องวันที่กดแล้วเลือกจากปฏิทิน ไม่ต้องพิมพ์เอง แต่ยังพิมพ์ลงกระดาษเป็น `11/08/2569` เหมือนเดิม

เก็บสองค่าคู่กันจากการเลือกครั้งเดียว จึงไม่มีทางไม่ตรงกัน:

| field | ตัวอย่าง | ใช้ทำอะไร |
|---|---|---|
| `date` | `11/08/2569` | ข้อความที่พิมพ์ลงกระดาษ |
| `issuedAt` | `2026-08-11` | ให้ระบบค้นและจัดกลุ่มยอดรายเดือน |

**หน้าสรุปยอดนับตามวันที่บนบิล ไม่ใช่วันที่กดบันทึก** เพราะ ภ.พ.30 ยื่นตามวันที่ใบกำกับภาษี
ออกบิลลงวันที่ 31 ก.ค. แล้วมาบันทึกวันที่ 2 ส.ค. ยอดต้องอยู่เดือนกรกฎาคม

บิลเก่าที่เก็บวันที่เป็นข้อความล้วน (`20 ก.ค. 69`) ถูกแปลงให้ด้วย `npm run repair`
ใบที่อ่านไม่ออกจะถอยไปใช้วันที่บันทึกแทน ไม่เดาวันที่ใส่ให้เอกสารภาษี

## ซ่อมบำรุงข้อมูล

```bash
npm run repair              # ซ่อมจริง
npm run repair -- --dry-run # ดูก่อนว่าจะแก้อะไร
```

รันซ้ำได้เสมอ ไม่มีขั้นตอนไหนทำลายข้อมูล — ทุกอย่างที่เขียนทับเป็นค่าที่คำนวณ
หรืออ่านจาก field อื่นได้อยู่แล้ว

1. คำนวณยอดรวม (`totalSatang`) ใหม่จากรายการสินค้า
2. เติมวันที่บนบิล (`issuedAt`) จากข้อความวันที่เดิม
3. รายงานเลขที่เอกสารที่ซ้ำกัน (แก้เองเท่านั้น เพราะต้องเลือกว่าจะแก้ใบไหน)

## นำเข้า / สำรองข้อมูล

หน้า **นำเข้า / สำรอง** รับไฟล์สองแบบ:

| ไฟล์ | มาจาก | ผลลัพธ์ |
|---|---|---|
| `billkp-backup-<วันที่>.json` | ปุ่ม **ดาวน์โหลดข้อมูลทั้งหมด** ของระบบนี้ | ใบที่ยังอยู่ในระบบถูกอัปเดตทับ ใบที่ไม่มีแล้วถูกเพิ่มกลับ |
| `historyData<วันที่>.json` | เว็บเวอร์ชันเดิม → หน้า **ประวัติ** → **สำรองข้อมูล** | เพิ่มเป็นบิลใหม่ทั้งหมด |

ไฟล์สำรองของระบบนี้จึง **กู้กลับได้จริง** และกู้ไฟล์เดิมซ้ำสองครั้งก็ได้ผลเท่ากับครั้งเดียว
ไม่เกิดบิลซ้ำ (ยึดจาก id ของบิล และเขียนทับได้เฉพาะบิลของเจ้าของบัญชีเดียวกันเท่านั้น)

ตัวแปลงไฟล์ของระบบเดิมจะจัดการให้อัตโนมัติ:

- แปลงเงินจาก string แยกบาท/สตางค์ เป็นจำนวนเต็มสตางค์
  (ช่องสตางค์เดิมเป็น *หลักทศนิยม* — `"5"` = 50 สตางค์ ไม่ใช่ 5 สตางค์)
- รวมเลขผู้เสียภาษี 13 ช่องเป็นสตริงเดียว
- คงวันที่เดิมของบิลไว้ ไม่ใช่วันที่นำเข้า

**การนำเข้าจะไม่ลบข้อมูลเดิมทิ้งทั้งก้อน** ต่างจากเวอร์ชันเดิมที่เขียนทับทั้งชุด

## การพิมพ์ / ออก PDF

กดปุ่ม **พิมพ์ / PDF** → ในกล่องพิมพ์เลือกปลายทางเป็น **Save as PDF** ก็ได้ไฟล์ PDF

- เลือก **A4** หรือ **A5** ได้ที่แถบเครื่องมือ ระบบจะตั้ง `@page size` ให้เอง
  ตั้งค่า margin ในกล่องพิมพ์เป็น **None** และปิด **Headers and footers**
- ตัวหนังสือเป็น vector จริง คมทุกระดับซูม ไฟล์เล็กกว่าวิธีเดิมหลายเท่า
  และไม่มีปัญหาสระ/วรรณยุกต์ลอยผิดตำแหน่งแบบที่ html2canvas ทำ

## บั๊กของเวอร์ชันเดิมที่แก้ไปแล้ว

| บั๊ก | อาการ |
|---|---|
| `import Controller from "./components/controller"` แต่ไฟล์ชื่อ `Controller.tsx` | build ผ่านบน Windows แต่พังทันทีบน Linux ของ Vercel |
| `html2canvas` / `jspdf` ไม่ได้อยู่ใน `package.json` | รอดเพราะเป็น transitive dep ของ `html2pdf.js` — พังทันทีที่ html2pdf อัปเวอร์ชัน |
| แปลงเงินเป็นตัวอักษรไทยไม่รองรับเกิน 7 หลัก | 10,000,000 บาท → `"หนึ่งundefined..."` |
| คำนวณภาษีแล้วปัดบาท/สตางค์แยกกัน | ภาษี 6.995 → แสดง `"6.100"` ซึ่งไม่ใช่จำนวนเงินที่มีอยู่จริง |
| `backupDataToJsonFile2()` ผูก `window.addEventListener('focus')` โดยไม่เคยถอด | กด "ล้างประวัติ" หลายครั้ง listener ซ้อนกันและลบ `localStorage` ซ้ำ |
| กล่องยืนยันซ่อนด้วย `top:-150px` แต่ยังอยู่ใน DOM | กด Tab ไปโฟกัสปุ่ม "ใช่" ที่มองไม่เห็นแล้วลบข้อมูลได้ |
| ยอดรวมอัปเดตผ่าน state `refresh` ที่ต้อง toggle เอง | ลืม toggle ช่องไหน ยอดของช่องนั้นไม่ขยับ |
